# Diagnostic-specific example database

Revised requirement: a star needs applicable distinguishing observations, not all measurements. Preserve the 15,000-star database. Different stars may use different diagnostic families.

Checklist:
- [ ] Audit every observed record with at least one usable additional diagnostic.
- [ ] Verify measured values, units, quality flags and reference provenance.
- [ ] Evaluate each diagnostic separately against the same temperature/luminosity solutions; do not let an unrelated uncalibrated measurement veto a usable diagnostic.
- [ ] Record which competing phases each diagnostic actually scores and separates. Unsupported alternatives remain unsupported, not ruled out.
- [ ] Save qualified examples and rejected/unsupported records, including disagreements; never select on agreement with catalog labels.
- [ ] Assess class and stage coverage explicitly before claiming a representative sample.
- [ ] Integrate only after the coverage and measurement checks pass.

Keep observed measurements, calibration applicability, and reference classifications in separate fields. A nonuniform relative-fit score demonstrates model sensitivity, not independent confirmation or complete stage resolution. Report selection effects: this is a diagnostic demonstration/validation cohort, not a population-frequency sample. Do not claim spectral classes are nuclear-burning stages.

# Diagnostic-specific example database

Revised requirement: a star needs applicable distinguishing observations, not all measurements. Preserve the 15,000-star database. Different stars may use different diagnostic families.

Checklist:
- [x] Audit collected records with usable diagnostics, and sourced single-position benchmarks.
- [x] Verify measured values, units, quality flags and reference provenance.
- [x] Evaluate each diagnostic separately against the same temperature/luminosity solutions; do not let an unrelated uncalibrated measurement veto a usable diagnostic.
- [x] Record which competing phases each diagnostic actually scores and separates. Unsupported alternatives remain unsupported, not ruled out.
- [x] Save qualified examples and rejected/unsupported records, including disagreements; never select on agreement with catalog labels.
- [x] Assess class and stage coverage explicitly before claiming a representative sample.
- [x] Integrate supported examples with explicit gaps, after measurement, phone and live checks. Do not claim exhaustive representative coverage.

Delivered: 133 examples in eight reference groups, with 3,628 records retained in the full audit database. Published and live-verified at `https://akingry.github.io/stellar-measurement-lab/?v=22`. Twenty-two leading fits disagree; nine have non-comparable reference/model categories. Remaining scope gaps are listed in `EXAMPLE-CHECKLIST.md` and the sample manifest.

Keep observed measurements, calibration applicability, and reference classifications in separate fields. A nonuniform relative-fit score demonstrates model sensitivity, not independent confirmation or complete stage resolution. Report selection effects: this is a diagnostic demonstration/validation cohort, not a population-frequency sample. Do not claim spectral classes are nuclear-burning stages.
